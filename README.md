# 📝 Mistral AI Text Summarizer

A simple and beginner-friendly text summarization application built with **Python, Streamlit, and Mistral AI**.

## 🚀 Features

- 🔐 Secure API key input
- 📝 Summarize long text
- ⚙️ Short, Medium, and Detailed summaries
- 📊 Original and summary word counts
- ⬇️ Download the generated summary
- ⚠️ Handles API errors such as rate limits and invalid API keys
- 💻 Simple and easy-to-use interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Mistral AI API
